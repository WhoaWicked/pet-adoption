# Plan: landing-page รอบ 2 — ออกแบบหน้า landing ใหม่ตาม brief

branch: `claude/chore/ui-friendly` · ต่อจาก `e5c00ff` (รอบ 1: landing ที่ "/" + รายการย้ายไป "/pets") · ใช้ skill `frontend-design:frontend-design` ตรวจ

## Context
routing และลิงก์ทำเสร็จแล้วในรอบ 1 (ตรวจซ้ำแล้ว: ลิงก์ที่ยังชี้ "/" เหลือแค่ wordmark ใน Header และ "กลับหน้าแรก" ใน NotFound ซึ่งตั้งใจให้ไป landing)
รอบนี้จัดหน้า landing ใหม่ทั้งหน้าตาม brief: ลำดับส่วนใหม่, hero จัดกลาง, กรอบรูปใหญ่, การ์ด 3 ใบ, FAQ, footer มีลิงก์

**ภาพอ้างอิง:** ไม่มีภาพแนบมาในข้อความ → ทำตามคำอธิบายใน brief อย่างเดียว

**ขอบเขต:** แตะเฉพาะ `web/src/features/landing/`, `web/src/pages/LandingPage.tsx` และ footer ใน `AppLayout.tsx` (ดูข้อ 7) · ไม่แก้ BE · ไม่เพิ่ม endpoint · ไม่แก้ logic ของฟีเจอร์เดิม · ใช้ Header เดิม · ไม่เพิ่มสี (ใช้ token ใน `index.css`) · ไม่เพิ่ม dependency · ไม่ commit

## งานที่จะทำ

### 1. Hero — `features/landing/LandingHero.tsx` (เขียนใหม่)
- จัดกลาง ไม่มีแถบพื้นสี ไม่มี badge
- หัวข้อ 2 บรรทัด (แต่ละบรรทัดเป็น block): "ให้น้องได้มีบ้าน" / "ที่รักและพร้อมดูแล" · Anuphan, `leading-[1.3]`, ไม่มี letter-spacing ติดลบ
- คำอธิบาย 2–3 บรรทัด สี `muted-foreground` กว้างไม่เกิน ~36rem
- ปุ่มหลักแคปซูล (`rounded-full`, สูง 40px, เขียวทึบ) "ดูน้อง ๆ ทั้งหมด" → `/pets`
- ลิงก์รอง "ลงประกาศหาบ้านให้น้อง" → `/pets/new` (`RequireAuth` เดิมพาไป login แล้วกลับมาเองถ้ายังไม่ล็อกอิน)

### 2. กรอบรูปใหญ่ — `features/landing/PhotoShowcase.tsx` (ใหม่)
- **เลือกแบบ 3 รูปเรียงกันในกรอบเดียว:** เห็นน้องหลายตัวตั้งแต่แรก และกรอบไม่ว่างเปล่าแม้รูปบางตัวจะเป็นแนวตั้ง/แนวนอนต่างกัน
  - กรอบนอก: `rounded-[1.5rem]` (24px) `border` 1px พื้น `card` padding เล็ก ๆ · ข้างในเป็นกริด 3 ช่อง ช่องกลางกว้างกว่า
  - มือถือ (< `sm`): แสดงแค่รูปแรก เพื่อไม่ให้รูปเล็กจนดูไม่ออก
- ใต้แต่ละรูป: ชื่อ (ตัวหนา) + จังหวัด ตัวเล็กสี muted · แต่ละรูปเป็นลิงก์ไปหน้าน้อง
- ข้อมูล: น้องที่มี `image_url` และไม่อยู่ในกริด 4 ตัวล่าสุดก่อน (ไม่เห็นตัวเดิมซ้ำ) ถ้าไม่พอค่อยใช้ตัวที่มีรูปตัวอื่น
- โหลดอยู่: Skeleton ในกรอบ · ไม่มีน้องที่มีรูปเลย/โหลดไม่สำเร็จ: ซ่อนทั้งส่วน (ไม่ใช้รูปสต็อก ไม่แสดงกรอบว่าง)

### 3. "ทำงานยังไง" — `features/landing/HowItWorks.tsx` (เขียนใหม่)
- หัวข้อกลาง + การ์ดเท่ากัน 3 ใบ (`md` ขึ้นไป 3 คอลัมน์, มือถือเรียงลง)
- แต่ละใบ: ไอคอนเส้นบาง (lucide `strokeWidth` 1.5: `SearchIcon`, `SendIcon`, `ClipboardCheckIcon`) + ป้ายเลข "ขั้นที่ 1" (ชิปโทนเขียวอ่อน `status-available`) + ชื่อ 2–5 คำ + คำอธิบาย 2–3 บรรทัด
- การ์ด: `border` 1px `rounded-[1.25rem]` พื้น `card` ไม่มีเงา · ไอคอนวางตรง ๆ ไม่มีกล่องซ้อน
- เนื้อหาเหมือนรอบ 1 (ตามที่ระบบทำจริง) ขยายคำอธิบายให้เป็น 2–3 บรรทัด

### 4. "น้อง ๆ ที่รอบ้าน" — `features/landing/LatestPets.tsx` (ปรับ)
- หัวข้อ + คำอธิบายย้ายมากลางหน้า · ลิงก์ "ดูทั้งหมด" ย้ายไปไว้ใต้กริด (ปุ่มแคปซูลรอง) ให้แกนกลางหน้าตรงกัน
- loading / empty / error ใช้ของเดิม

### 5. FAQ — `features/landing/Faq.tsx` (ใหม่)
- หัวข้อกลาง + กริด 2 คอลัมน์ (`md` ขึ้นไป) กล่องพื้น `muted` `rounded-[1.25rem]` ไม่มีขอบ ไม่มีเงา
- 4 ข้อตามตารางด้านบน แสดงคำตอบเลย ไม่ใช้ accordion (มีแค่ 4 ข้อ สั้น อ่านได้ทันที)
- ใช้ `<dl>` / `<dt>` / `<dd>` ให้ screen reader รู้ว่าเป็นคู่ถาม-ตอบ

### 6. ปิดท้าย — `features/landing/ClosingCta.tsx` (เขียนใหม่)
- จัดกลาง ไม่มีแถบพื้นสี · หัวข้อ 2 บรรทัด "มีน้องที่กำลังหาบ้านใหม่อยู่ไหม" / "ลงประกาศให้คนที่พร้อมได้เห็น" · ปุ่มหลัก "ลงประกาศหาบ้านให้น้อง" + ปุ่มรอง (ขาวขอบเทา) "ดูน้อง ๆ ทั้งหมด"

### 7. Footer — `components/layout/AppLayout.tsx`
- เปลี่ยน footer กลางของแอป (มีทุกหน้า) เป็น: เส้นขอบบน 1px · ชื่อเว็บ "บ้านใหม่" + ประโยคเดิม · ลิงก์หลัก (หน้าแรก, ดูน้อง ๆ, ลงประกาศ) · ไม่มี social
- **เหตุผล:** ถ้าทำ footer เฉพาะหน้า landing จะซ้อนกับ footer กลางที่มีอยู่ การปรับ footer กลางทำให้ทุกหน้าได้ลิงก์หลักด้วย และไม่แตะ logic ใด ๆ
- ส่วนนี้แตะนอกไฟล์ landing → **ขอยืนยันก่อน** (ถ้าไม่ต้องการ จะซ่อน footer กลางเฉพาะหน้า "/" แล้วทำ footer ของ landing แทน)

### 8. ปุ่มแคปซูล
- ใช้ `Button` เดิม `size="default"` (สูง 40px) + `className="rounded-full"` · ปุ่มรอง `variant="outline"` + `bg-card` (ขาว) ขอบ `border-field-border`
- ไม่แก้ `button.tsx` (ไม่กระทบปุ่มทั้งแอป)

### 9. การเคลื่อนไหว — `features/landing/Reveal.tsx` (ใหม่)
- component เล็ก ๆ ใช้ `IntersectionObserver`: เลื่อนมาถึงแล้ว fade + slide ขึ้น 16px ครั้งเดียว
- ใช้ `motion-safe:` เท่านั้น → ผู้ใช้ที่ตั้ง reduced-motion เห็นเนื้อหาทันทีไม่มีอนิเมชัน · ไม่รองรับ IntersectionObserver ก็แสดงทันที
- hover: การ์ด "ทำงานยังไง" ขอบเข้มขึ้นเล็กน้อย, ปุ่มใช้ hover เดิม, รูปใน PetCard ซูมช้า ๆ (เดิม) · ไม่มี parallax

### 10. มุมโค้ง
- token `--radius-*` ตอนนี้เท่ากัน 12px ทั้งแอป → ใช้ค่าแบบระบุเฉพาะจุดในหน้า landing (`rounded-[1.5rem]`, `rounded-[1.25rem]`) ไม่แก้ token (ไม่กระทบหน้าอื่น)
