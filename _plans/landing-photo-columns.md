branch: `claude/chore/ui-friendly` · ผู้ใช้อนุมัติให้ implement ต่อจากแผนได้เลย · CSS keyframes ล้วน ไม่มีไลบรารีใหม่ · ไม่ commit

## ข้อมูล
- ใช้ `usePetsList({ page: 1 })` ที่ landing ดึงอยู่แล้ว (สูงสุด 12 ตัว ตาม `PETS_PAGE_SIZE`) · ตอนนี้มีรูป 9 ตัว ≥ 6 จึงไม่ต้องเรียกเพิ่ม
- ใช้ทุกตัวที่มี `image_url` (ตัวที่ไม่อยู่ในกริด "ล่าสุด" ก่อน) · ถ้าไม่พอ ทำซ้ำรายการจนแต่ละคอลัมน์มีอย่างน้อย 4 รูป
- ไม่แก้ hook / API / query key

## โครง (`features/landing/PhotoShowcase.tsx` เขียนใหม่)
- กรอบเดิม: `rounded-[1.5rem] border bg-card p-2 sm:p-3` · ช่องแสดงผลสูงคงที่ `h-[26rem] sm:h-[30rem] lg:h-[34rem]` `overflow-hidden` + mask จางขอบบน/ล่าง (mask ไม่ใช่สีไล่ตกแต่ง)
- 3 คอลัมน์ (`sm` ขึ้นไป) / 2 คอลัมน์ที่ 375px (คอลัมน์ 3 ซ่อนบนมือถือ) · กระจายรูปแบบ round-robin
- รูป 4:5 ทุกใบ โค้ง 16px ระยะห่างเท่ากัน + ชื่อน้องตัวเล็กใต้รูป
- **วนไม่สะดุด:** แต่ละคอลัมน์มีรายการ 2 ชุดเรียงต่อกัน เลื่อน `translateY(0 → -50%)` (ขึ้น) หรือ `-50% → 0` (ลง) · ระยะห่างใช้ padding ล่างของแต่ละรูป (ไม่ใช้ gap) ให้ -50% ตรงรอยต่อพอดี
- **ชุดซ้ำ:** `aria-hidden` และเป็น `div` ไม่ใช่ลิงก์ → ไม่มีลิงก์/โฟกัสซ้ำ · ชุดแรกเป็นลิงก์ไปหน้าน้อง
- ทิศสลับ: คอลัมน์ 1 ขึ้น · 2 ลง · 3 ขึ้น · 48s / 56s / 52s ต่อรอบ linear infinite (เร็วต่างกันเล็กน้อยไม่ให้ดูซิงก์กัน)
- ชี้เมาส์ (หรือโฟกัสลิงก์ข้างใน) ที่กรอบ → `animation-play-state: paused`
- transform อย่างเดียว · กล่องรูปกำหนดสัดส่วนไว้ (กัน CLS) · `PetImage` เดิมโหลดแบบ `loading="lazy"`
- **reduced-motion:** `motion-reduce:animate-none` → คอลัมน์หยุดนิ่งเป็นกริด (ชุดซ้ำซ่อน)
- ไม่ห่อด้วย `Reveal` (ไม่เพิ่มอนิเมชันอื่น)

## สถานะ
- กำลังโหลด: skeleton คอลัมน์ในกรอบความสูงเดียวกัน (ไม่ใช่กรอบว่าง)
