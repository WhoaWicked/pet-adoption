## ⚠ สิ่งที่ไม่มีในระบบ
- **ไม่มีฟอร์มแก้ไขสัตว์:** API มีแค่ `POST /pets` และ `PATCH /pets/:id/close` (ไม่มี endpoint แก้ไข) และไม่มี route/หน้าแก้ไขใน web → ไม่สร้าง (เป็นฟีเจอร์ใหม่)
- **ไม่มีพรีวิวรูป** ในฟอร์มเดิม → ไม่เพิ่ม
- **ไม่มีปุ่ม "แก้ไข"** ในรายการสัตว์ของฉัน → ใช้ปุ่ม "จัดการ" ไป `/my-pets/:id` (ปลายทางเดิมของการ์ด)

## งาน
1. **`PageHeader`** — หัวข้อขนาดเดียวกับหน้าอื่น (`text-3xl sm:text-4xl`) ระยะ `mb-8` · props เดิม
2. **`CreatePetPage`** — กว้าง `max-w-[40rem]` (640px) กลางหน้า · เอากล่องรอบฟอร์มออก (ฟอร์มวางบนพื้นหน้า แบ่งกลุ่มด้วยเส้นคั่น)
3. **`CreatePetForm`** (ฟิลด์ / validation / ข้อความ / enum / การส่ง / redirect เดิม):
   - แบ่ง 3 กลุ่ม หัวข้อย่อย `text-lg font-semibold` + เส้นบนบาง: **ข้อมูลน้อง** (ชื่อ, ชนิด | จังหวัด 2 คอลัมน์, อายุ) · **รายละเอียด** (เกี่ยวกับน้อง, เงื่อนไข) · **รูปภาพ** (ลิงก์รูป + ข้อความช่วยเดิม)
   - ปุ่มท้ายฟอร์ม: หลัก "ลงประกาศ" (แคปซูล + ไอคอนหมุนระหว่างส่ง + disabled เดิม) + รอง "ยกเลิก" (แคปซูลขอบเทา: มี history → ย้อนกลับ, ไม่มี → `/my-pets`) · มือถือเรียงลงเต็มความกว้าง
4. **`MyPetsPage`** — เปลี่ยนจากกริดการ์ดเป็นแถวแบบหน้า "คำขอของฉัน" (ไม่มีกล่อง คั่นด้วยเส้นบาง):
   รูปเล็ก 64px (`PetImage` เดิม โค้ง 12px) · ชื่อ + ชนิด·อายุ·จังหวัด · "ลงเมื่อ {วันที่}" · ป้ายสถานะ (`PetStatusBadge` ทุกสถานะ เพราะในหน้านี้สถานะเป็นข้อมูลสำคัญของเจ้าของ) · ปุ่มแคปซูล "จัดการ" → `/my-pets/:id`
   หัวหน้า: "สัตว์ของฉัน" + "ลงประกาศไว้ n ตัว" + ปุ่ม "ลงประกาศ" · skeleton ทรงแถว · ว่าง/error เดิม (ปุ่มแคปซูล)
5. **`ApplyForm`** — ปรับไปแล้ว (ปุ่มแคปซูล, error ใต้ช่อง, ข้อความช่วยตัวนับ) → ไม่แก้เพิ่ม ถ่ายภาพสถานะ error ให้ดู
