## ข้อมูลที่มีจริงใน API (`Pet`)
`name`, `species`, `age_months`, `province`, `description`, `requirements`, `image_url`, `status`, `created_at`
→ **ไม่มีเพศและขนาด** จึงไม่แสดง (ไม่แต่งเพิ่ม) · รายการข้อมูลหลักจะมี: ชนิด, อายุ, จังหวัด, ลงประกาศเมื่อ (`created_at`)

## ⚠ เรื่อง "ส่งคำขอแล้ว" ที่ต้องแจ้งก่อน
ระบบเดิม **ไม่ได้ดึงสถานะคำขอของเรามาแสดงในหน้านี้** (pending/approved/rejected/withdrawn ดูได้ที่หน้า "คำขอของฉัน" เท่านั้น):
- ส่งสำเร็จ → ฟอร์มถูกแทนด้วยข้อความ "ส่งคำขอรับเลี้ยง … แล้ว" + ลิงก์ "ดูคำขอของฉัน"
- เคยส่งไว้แล้วแล้วกดส่งซ้ำ → API ตอบ 409 → toast แจ้งเตือน
การแสดงสถานะคำขอในหน้านี้ต้องเพิ่มการดึงข้อมูล (hook/logic) ซึ่งอยู่นอกขอบเขต → **รอบนี้คงพฤติกรรมเดิม** ออกแบบข้อความสำเร็จให้ดูดี

## งานที่จะทำ

### 1. โครงหน้า — `PetDetailPage.tsx`
- **ลิงก์ย้อนกลับ:** ข้อความ "กลับไปดูน้อง ๆ ทั้งหมด" · logic เดิม (มี history → ย้อนกลับ ซึ่งรักษาตัวกรองที่ใช้ใน `/pets`, ไม่มี → ไป `/pets`)
- **จอ `lg`:** 2 คอลัมน์ `[1.1fr_1fr]` gap กว้าง
  - ซ้าย: รูปใหญ่ 4:3 `rounded-[1.5rem]` (มุมกรอบรูปใหญ่ตาม DESIGN.md) **ซ้ายเป็นฝั่ง sticky** แทนขวา เพราะคอลัมน์ขวามีคำอธิบาย + ฟอร์มที่ยาวกว่าจอ ถ้าให้ขวา sticky ส่วนล่างของฟอร์มจะเลื่อนไม่ถึง
  - ขวา: ข้อมูล → คำอธิบาย → เงื่อนไข → กล่องรับเลี้ยง
- **มือถือ:** เรียงลงตามลำดับ DOM เดียวกัน: รูป → ชื่อ → ข้อมูล → คำอธิบาย → ปุ่ม/ฟอร์ม
- **ส่วนหัวข้อมูล:** ป้ายสถานะแสดงเฉพาะเมื่อไม่ใช่ "รอบ้าน" (แบบเดียวกับการ์ด) · ชื่อ `h1` `text-3xl sm:text-4xl font-bold` · `SaveButton` แคปซูลรอง (`rounded-full border-field-border/50 bg-card`)
- **รายการข้อมูลหลัก:** `<dl>` 2 คอลัมน์ (ป้ายสีเทา / ค่า) แต่ละแถวคั่นด้วยเส้นบน 1px `border-border` ไม่มีกล่อง
- **คำอธิบาย / เงื่อนไข:** หัวข้อย่อย `text-lg font-semibold` + เนื้อความ `max-w-prose` `whitespace-pre-line` (เดิม) สี foreground ให้อ่านง่ายกว่าเดิมที่เป็นสีเทา
- **loading:** skeleton ตามโครงใหม่ (รูป 4:3 โค้ง 24px ซ้าย + แถวชื่อ/รายการ/ย่อหน้าขวา)
- **404:** `EmptyState` เดิม + ปุ่มแคปซูล "กลับไปดูน้อง ๆ ทั้งหมด" · **error:** `ErrorState` เดิม (ปุ่มแคปซูล "ลองใหม่" อยู่แล้ว)

### 2. กล่องรับเลี้ยง — `AdoptionPanel.tsx` (เงื่อนไขและลำดับ if เดิมทุกข้อ)
- กล่อง: การ์ดตาม DESIGN.md `rounded-[1.25rem] border bg-card p-6` ไม่มีเงา (แทนพื้น primary จาง + ring)
- หัวข้อ "ขอรับเลี้ยง {ชื่อ}" `text-xl font-semibold`
- ข้อความแทนฟอร์ม (`Notice`): ไอคอนเส้นบางในวง `bg-muted` + หัวข้อ + คำอธิบาย + ปุ่มแคปซูล
  - เจ้าของ → ปุ่มหลัก "ไปหน้าจัดการ" · ยังไม่ login → ปุ่มหลัก "เข้าสู่ระบบ" · มีบ้านแล้ว / ปิดรับ → ข้อความ + ลิงก์ "ดูน้องตัวอื่น" ไป `/pets` (ลิงก์นำทางเท่านั้น ไม่ใช่ logic ใหม่)
- จัดชิดซ้ายแทนกึ่งกลาง ให้เข้ากับคอลัมน์ข้อมูล

### 3. ฟอร์ม — `ApplyForm.tsx` (ฟิลด์ / validation / flow เดิม)
- ปุ่มส่ง: แคปซูลหลักเต็มความกว้าง ข้อความ **"ส่งคำขอรับเลี้ยง"** (เดิม "ยื่นคำขอรับเลี้ยง" — เปลี่ยนตาม brief) ตอนส่ง "กำลังส่งคำขอ…" เหมือนเดิม
- ระยะห่างระหว่างฟิลด์ `space-y-6` · ข้อความ error ใต้ฟิลด์คงเดิม (มีอยู่แล้วทุกฟิลด์)
