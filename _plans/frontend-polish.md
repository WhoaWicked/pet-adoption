# Plan: frontend-polish — ปรับดีไซน์ 5 เรื่อง

spec: `_specs/frontend-mvp.md` (ส่วน Design) · branch: `claude/feature/frontend-polish` · ใช้ skill `frontend-design:frontend-design` ตรวจ

## Context
frontend MVP ใช้งานได้ครบทุกหน้าแล้ว แต่ทำโดยยังไม่มี skill `frontend-design` รอบนี้ตรวจ UI ทั้งหมดแล้วเลือกปรับไม่เกิน 5 เรื่องที่กระทบความรู้สึกโดยรวมมากที่สุด โดยคงโทนอบอุ่น เรียบ สะอาดตาม spec

**ขอบเขต:** ปรับเฉพาะหน้าตา (สไตล์, ค่าใน token, spacing, ลำดับความเด่น) · ไม่เปลี่ยน logic, API, โครงไฟล์, query keys · ไม่เพิ่ม dependency · ใช้ token ชุดเดิม (ปรับค่าได้ ไม่เพิ่มสีใหม่ ไม่ hard-code) · ต้องใช้ได้ที่ 375px · ไม่แตะ `api/` · ไม่ commit

## สิ่งที่ตรวจเจอ
- สีหลัก `--primary` (oklch L 0.60) บนตัวอักษรขาว contrast ประมาณ **3.9:1** (ประมาณจากความสว่าง) ต่ำกว่า 4.5:1 ที่ข้อความบนปุ่มควรได้
- หัวข้อใช้ `tracking-tight` (3 ไฟล์) ซึ่งบีบสระและวรรณยุกต์ภาษาไทยให้ชิดกัน และขนาดหัวข้อไม่เป็นชุดเดียวกันทั้งแอป
- ปุ่ม/ช่องกรอกของ shadcn ตั้งต้นสูง 32px ผมจึงเขียนทับรายหน้าไว้ 58 จุด (`h-9` 5, `h-10` 38, `h-11` 15) แต่ Select ในฟอร์มบางจุดยังสูง 32px อยู่ ขนาดจึงไม่เท่ากันและเป้าแตะบนมือถือเล็ก
- 12 จุดใช้กล่องหน้าตาเดียวกัน `rounded-2xl border bg-card` (การ์ดสัตว์, แถบ filter, รายการคำขอ, กล่องรับเลี้ยง ฯลฯ) ทุกอย่างจึงเด่นเท่ากันหมด
- หน้ารายละเอียดและหน้าจัดการไม่มีจุดที่สายตาควรไปก่อน: ปุ่มยื่นคำขอจมอยู่ล่างสุด และคำขอที่รอตัดสินหน้าตาเหมือนคำขอที่จบไปแล้ว

## 5 เรื่องที่จะปรับ

### 1. สีหลักเข้มขึ้นให้อ่านง่าย — `index.css`
- ลด L ของ `--primary` / `--ring` จาก 0.60 → ราว 0.53 (hue โทนอุ่นเดิม) ให้ข้อความขาวบนปุ่มได้ ≥ 4.5:1
- เกลี่ย `--secondary` / `--muted` / `--border` ให้ต่างกันชัดขึ้นเล็กน้อย เพื่อใช้แยกระดับพื้นผิวในข้อ 4
- **เหตุผล:** ปุ่มสีหลักคือ action สำคัญทุกตัว (ยื่นคำขอ, อนุมัติ, ลงประกาศ, login) ต้องอ่านออกก่อนอย่างอื่น

### 2. ตัวอักษรไทยหายใจได้ และมีลำดับขนาดชุดเดียว — `index.css` + หัวข้อ
- เอา `tracking-tight` ออกจากหัวข้อไทยทั้งหมด และตั้ง `line-height` ของ body ให้โปร่งขึ้น (~1.7) เพราะภาษาไทยมีสระบน/ล่าง
- ใช้ขนาดหัวข้อ 3 ระดับทั้งแอป: ชื่อหน้า / หัวข้อส่วน / ชื่อบนการ์ด แยกด้วยน้ำหนัก (bold / semibold) ให้ชัดกว่าตอนนี้
- **เหตุผล:** ตัวอักษรเป็นสิ่งที่เห็นมากที่สุดในทุกหน้า ภาษาไทยที่ถูกบีบจะดูแน่นและไม่อบอุ่น

### 3. ปุ่มและช่องกรอกขนาดเดียวกันทั้งแอป — `components/ui/{button,input,select,textarea}.tsx` + ลบ override รายหน้า
- ตั้งค่าเริ่มต้น: ปุ่ม `default` สูง 40px, `lg` 44px, input/select 40px (ฟอร์มหลัก 44px ผ่าน `size`) แล้วลบ `h-9`/`h-10`/`h-11` ที่เขียนทับไว้รายหน้า
- **เหตุผล:** ขนาดที่ไม่เท่ากันทำให้ดูไม่เรียบร้อย และเป้าแตะ 32px เล็กเกินไปบนมือถือ การตั้งที่ต้นทางทำให้หน้าใหม่ได้ขนาดถูกเองโดยไม่ต้องจำ

### 4. แยกระดับพื้นผิว ไม่ใช่ทุกอย่างเป็นการ์ดมีเส้นขอบ — การ์ดสัตว์, filter, รายการ
- การ์ดสัตว์: ให้รูปเป็นตัวเด่น (รูปมุมโค้งเต็มบล็อก, ตัดเส้นขอบรอบการ์ด, ข้อความวางบนพื้นหลังหน้าโดยตรง) และเอาการขยายรูปตอน hover ออก ใช้แค่ focus/hover ที่เงียบกว่า
- แถบ filter และรายการคำขอ: เปลี่ยนจากกล่องมีเส้นขอบเป็นพื้นผิว `secondary`/`muted` ไม่มีเส้น
- เก็บเส้นขอบไว้เฉพาะกล่องที่ต้องแยกเนื้อหาจริง เช่น ฟอร์มลงประกาศ และ popover
- เปลี่ยนตัวคั่น `·` ใน meta ของการ์ดสัตว์/รายการคำขอ/หน้าจัดการ เป็นการแสดงแยกชิ้นด้วยไอคอนหรือระยะห่าง
- **เหตุผล:** หน้ารายการคือหน้าแรกที่คนเห็น สัตว์ควรเด่นกว่ากรอบ และการลดเส้นขอบทำให้หน้าเรียบและสะอาดขึ้นทันที

### 5. หน้ารายละเอียดและหน้าจัดการมีจุดเด่นจุดเดียว
- **รายละเอียด:** กล่องรับเลี้ยงเป็นพื้นผิวโทนสีหลักจาง (`bg-primary/…` จาก token เดิม) และบนจอใหญ่ติดอยู่ข้างรูปขณะเลื่อน (`sticky`) ข้อมูลชนิด/อายุ/จังหวัดเป็นแถวเงียบ ๆ ใต้ชื่อ
- **หน้าจัดการ:** คำขอที่รอพิจารณามีแถบสีหลักด้านซ้ายและปุ่มอนุมัติเด่น ส่วนคำขอที่จบแล้ว (อนุมัติ/ปฏิเสธ/ถอน) ลดความเด่นและย่อคำตอบ
- **เหตุผล:** ทั้งสองหน้าคือจุดที่ผู้ใช้ต้องตัดสินใจ (ยื่น / อนุมัติ) สายตาควรไปที่ action นั้นก่อน

## ที่ตั้งใจไม่ปรับรอบนี้
- header: โครงและลำดับลิงก์ใช้ได้แล้ว จะได้ผลจากข้อ 1–3 ไปด้วย (สีปุ่ม, ขนาดปุ่ม, ตัวอักษร)
- hue ของสีหลัก: spec กำหนด "สีหลัก 1 สีโทนอุ่น + พื้นขาวนวล" ไว้แล้ว จึงปรับแค่ความเข้มเพื่อ contrast ไม่เปลี่ยนโทน
