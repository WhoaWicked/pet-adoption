## สิ่งที่ตรวจเจอ
- กริดตอนนี้เป็น 2 คอลัมน์ตั้งแต่มือถือ และหน้า 1 ขยายการ์ดใบแรกเป็น 2x2 (`data-featured`) → การ์ดสัดส่วนไม่เท่ากัน ขัดกับ brief
- ชิปชนิดสัตว์ตอนนี้เป็นสี่เหลี่ยม `rounded-lg` และตอนเลือกเป็นพื้นดำ (`bg-foreground`) ไม่ตรงกับชิปใน DESIGN.md (แคปซูล โทน primary)
- บนมือถือ แถบตัวกรอง (ชิป 4 อัน + Select จังหวัด) ตัดเป็น 2–3 แถว และ sticky ทั้งก้อน กินพื้นที่จอ
- `PetCard` ใช้ใน 4 ที่: landing, `/pets`, `/saved`, `/my-pets` → แก้ตัวเดียว ทุกหน้าได้ผลเหมือนกัน (ตรงตาม brief ห้ามแยกสำเนา)
- `EmptyState` / `ErrorState` ใช้ทั้งแอป (8 หน้า) → แก้เฉพาะหน้าตา (ปุ่มแคปซูล) ไม่เปลี่ยน props และข้อความเดิมของหน้าอื่น
- react-query retry ตามสถานะ error (ดู `lib/query/query-client.ts`) → ตอนจำลอง error ต้องรอให้ retry ครบก่อนถ่ายภาพ

## งานที่จะทำ

### 1. ส่วนหัว — `PetsListPage.tsx`
- `h1` "น้อง ๆ ที่กำลังรอบ้าน" ขนาดเดียวกับหัวข้อส่วนของ landing (`text-3xl sm:text-4xl font-bold`) ไม่มี hero
- บรรทัดจำนวน (ข้อมูลจริงจาก `meta.total`):
  - ไม่กรอง: "พบ 9 ตัวที่เปิดรับคำขอ"
  - กรองอยู่: "พบ 3 ตัวที่ตรงกับตัวกรอง"
  - กำลังโหลด / error: "เลือกดูตามชนิดสัตว์และจังหวัดที่สะดวก" (ข้อความเดิม)

### 2. ตัวกรอง — `PetFilters.tsx` (props เดิมทุกตัว เรียก `onChange`/`onClear` แบบเดิม)
- **จอ `md` ขึ้นไป:** แถบบรรทัดเดียว sticky ใต้ header (แบบเดิม): ชิปชนิดสัตว์ → Select จังหวัด → "ล้างตัวกรอง" ชิดขวา ไม่มีกล่อง/การ์ดครอบ
- **มือถือ:** ปุ่มแคปซูล "ตัวกรอง" (ไอคอน `SlidersHorizontal` เส้นบาง) + จำนวนตัวกรองที่ใช้อยู่ในวงเล็บ เช่น "ตัวกรอง (2)"
  - กดแล้วกางแผงใต้ปุ่ม (ชิป + Select จังหวัดเต็มความกว้าง + ล้างตัวกรอง) ใช้ `useState` ฝั่ง UI เท่านั้น · ปุ่มมี `aria-expanded` / `aria-controls`
  - เลือกค่าแล้วผลอัปเดตทันทีเหมือนเดิม (ไม่มีปุ่ม "ใช้ตัวกรอง" เพราะ filter เดิมทำงานทันที)
  - แถบ sticky บนมือถือเหลือแค่แถวปุ่ม (ไม่บังจอ) แผงที่กางอยู่ใน sticky ด้วยเพื่อให้กดต่อได้
- **ชิป (ตาม DESIGN.md):** `rounded-full` สูง 40px · ปกติ `border-field-border/50 bg-card` · เลือกแล้ว `border-primary bg-primary/10 text-primary` (4.63:1) · ยังใช้ Radix `RadioGroup` เดิม (ลูกศรเลื่อนตัวเลือกได้)
- Select จังหวัด: ขอบแบบช่องกรอกเดิม ปรับเป็นแคปซูลให้เข้าชุด

### 3. กริด — `PetsListPage.tsx`
- `grid-cols-1` (375px) → `sm:grid-cols-2` → `lg:grid-cols-3` → `xl:grid-cols-4` · `gap-x-6 gap-y-10` เท่ากันทุกจอ
- ลบ `data-featured` (การ์ด 2x2) ออก → ทุกใบสัดส่วนเดียวกัน
- skeleton ตอนโหลดใช้กริดเดียวกัน 8 ใบ
- ยังคงจางลงระหว่างเปลี่ยนหน้า/filter (`data-stale` เดิม) และ pagination เดิม

### 4. การ์ด — `PetCard.tsx` (ตัวเดียว ใช้ทุกหน้า)
- รูป: เปลี่ยนสัดส่วนจาก 4:5 → **4:3 ทุกใบ** เหตุผล: ตอนนี้มือถือเป็น 1 คอลัมน์ 4:5 จะสูงราว 430px ต่อใบ เลื่อนยาวมาก 4:3 ยังให้รูปเด่นแต่เห็นหลายตัวกว่า และยังเข้ากับกริด 4 คอลัมน์ของ landing · มุมโค้ง `--radius` 12px (ตาม DESIGN.md)
- ข้อมูลใต้รูป: ชื่อ (`font-semibold`) / ชนิด · อายุ / จังหวัด (ไอคอน `MapPin` เส้นบาง สี muted) → ไม่มีข้อมูลอื่น
- ป้ายสถานะ: คง `hideAvailable` เดิม → หน้า `/pets` และ landing ไม่โชว์ "รอบ้าน" ซ้ำทุกใบ ส่วนหน้า `/saved` / `/my-pets` ยังโชว์ "มีบ้านแล้ว"/"ปิดรับแล้ว" เฉพาะใบที่ต่างจากปกติ
- ปุ่มบันทึก (`SaveButton variant="icon"`) มุมขวาบนของรูปเหมือนเดิม
- hover: ซูมรูปเบา ๆ `motion-safe` (เดิม) · `PetCardSkeleton` สัดส่วน 4:3 ตรงกับการ์ด
- ลบ `data-slot="pet-photo"` (ใช้แค่กับการ์ด 2x2 ที่ลบออก)

### 5. รูป — `PetImage.tsx`

### 6. สถานะ — `EmptyState.tsx`, `ErrorState.tsx`, `PetsListPage.tsx`
- `ErrorState`: ปุ่ม "ลองใหม่" เป็นแคปซูลรอง (`rounded-full border-field-border/50 bg-card`) ตาม DESIGN.md · ข้อความ error ภาษาไทยจาก `getErrorMessage` เดิม
- `EmptyState`: ไม่เปลี่ยนโครง (ไอคอนในวง primary/10 + หัวข้อ + คำอธิบาย + action) ปรับแค่ระยะให้เข้ากับหน้า
- กรองแล้วไม่พบ (`/pets`): "ยังไม่เจอน้องที่ตรงกับตัวกรองนี้" + "ลองเปลี่ยนชนิดสัตว์หรือจังหวัด หรือล้างตัวกรองเพื่อดูน้องทั้งหมด" + ปุ่มแคปซูล "ล้างตัวกรอง"
- ปุ่ม action ในหน้า `/pets` ทั้งหมดเป็นแคปซูล
